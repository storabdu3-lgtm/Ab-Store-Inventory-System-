# NexusStock — Vercel-ready build

React + Vite multi-store inventory/e-commerce application.

## Deploy to Vercel

1. Upload/push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework: **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Add the Firebase and Cloudinary `VITE_*` variables from `.env.example` in Vercel.
7. Redeploy after saving environment variables.

`vercel.json` handles SPA route refreshes.

See `VERCEL_DEPLOY.md` for Firebase and Cloudinary setup.
